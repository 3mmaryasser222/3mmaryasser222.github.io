# Ammar Yasser — Portfolio

Static portfolio site prepared for GitHub Pages.

## Suggested public repository

Create a public repository named `3mmaryasser222.github.io` under the GitHub account `3mmaryasser222`, then upload the contents of this folder to its `main` branch. Then enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / (root)**.

The expected site URL is `https://3mmaryasser222.github.io/`.

## Contents

- `index.html` — portfolio page
- `style.css` and `portfolio-enhancements.css` — layout, visual style, and motion
- `script.js` — language toggle, project result dialogs, and interactions
- `assets/` — portrait and the five certificate PDFs

The site is plain HTML, CSS, and JavaScript; no build step is required.
